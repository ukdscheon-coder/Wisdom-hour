# Wisdom Hour

Mobile-first multilingual proverb and idiom learning PWA.

## Deploy
Connect this repository to Vercel with framework preset Other, root directory `/`, no build command. Every push to `main` deploys automatically.

## Features
27 starter entries, meaning cards, quiz, saved entries, share, localStorage persistence, offline service worker.

## Limitations
Not yet an hourly push-notification service. Full public dataset ingestion and source-level license verification remain future work. No native iOS/Android app binaries.
